# 분석 결과 HTML 검토 보고서 · 2026-10-15

웹 분석 결과를 저장해 다른 검토자에게 전달하거나 서버 없이 다시 확인할 수 있도록 HTML 내보내기를 추가했습니다.
기존 JSON 저장과 Standalone Demo는 유지합니다. 이번 보고서는 웹에서 현재 보고 있는 실제 분석 결과의 스냅샷입니다.

## 사용법

1. ZIP을 업로드하고 개별 영향, 3단계 비교, PR/Commit 또는 기대 대상 평가를 실행합니다.
2. 변경점 선택 영역의 **HTML 보고서**를 누릅니다.
3. 저장된 `.html`을 브라우저에서 엽니다. 서버·네트워크·추가 라이브러리가 필요하지 않습니다.
4. 항목 제목을 눌러 접고 펼치거나 브라우저 찾기로 이름·경로·Node ID를 검색합니다.
5. 필요한 경우 브라우저 인쇄 기능을 사용합니다. Chromium 인쇄에서는 접힌 설명도 포함되도록 검증했습니다.

## 포함하는 내용

- 생성 시각(UTC), 프로젝트 식별자, 분석 클래스·노드·관계 수, 업로드 경고.
- 개별 시작점 CRI와 세부 근거, 중복 제거 영향 후보, 테스트 후보·소스 위치, 엔진이 반환한 대표 경로, 분석 설명.
- LOCAL/FEATURE/SYSTEM 비교와 직전 범위 대비 추가·제외 수, 범위별 상세 결과.
- PR/Commit의 BASE/HEAD, 사용자 선언, 매핑 방향, 검증 상태, 변경 파일별 매핑 사유, 중복 제거 요약과 개별 시작점 상세.
- 사용자 입력 기대 대상의 평가 지표와 일치·누락·기대 목록 밖 후보.

내용을 임의로 줄이지 않습니다. 경로는 엔진의 대표 경로 범위이며 소스 검증 차이 목록은 서버가 반환한 범위를 표시합니다.
모바일에서는 표를 항목별 세로 카드로 표시하고, 데스크톱·인쇄에서는 표를 사용합니다.

## 결과를 잘못 해석하지 않도록 한 동작

- 시작점이 없는 PR은 위험 점수를 0으로 표현하지 않고 **산출 안 됨**으로 표시합니다.
- PR 최고 CRI는 개별 시작점의 최댓값이며 PR 전체 점수로 표현하지 않습니다.
- 소스 검증을 하지 않았거나 완료하지 못했다면 상태와 경고를 남깁니다. 검증 불가를 Java 파일 0개 검증 성공처럼 표시하지 않습니다.
- GitHub 코드 링크는 내용 검증 상태·HEAD/BASE 방향·검증 SHA가 일치할 때만 만듭니다. ZIP 포장 폴더를 제거하고 검증한 버전의 줄 위치로 연결합니다.
- 검증 기록이 없는 일반 영향 분석은 소스 내용 검증 기록이 없다고 명시합니다.
- CRI는 장애 확률이 아니고, 테스트는 실행·커버리지 결과가 아닌 후보이며, 기대 대상 평가는 전체 서비스 정확도가 아님을 보고서 안에 설명합니다.
- 저장한 파일은 자동 갱신하지 않습니다. Java 소스 검증도 설정·리소스·의존성·실행 환경 검증을 포함하지 않습니다.

## 데이터 처리

보고서 생성에는 현재 분석 데이터만 전달하고 Token 입력값은 전달하지 않습니다.
동적 값은 HTML 텍스트·속성에 맞게 이스케이프합니다. 보고서에 실행 스크립트, 외부 폰트·이미지·스타일, 원본 JSON을 삽입하지 않습니다.
CSP도 외부 리소스와 실행 콘텐츠를 막도록 설정했습니다. 검증된 코드 링크는 사용자가 눌렀을 때만 외부 페이지로 이동합니다.
공유 여부와 수신자는 사용자가 결정하며 자동 전송은 하지 않습니다.

## 이번에 실행한 검증

| 검사 | 결과 |
|---|---|
| 실제 frontend TypeScript + Vite build | 통과 |
| backend/frontend semantic 검사 | 통과 |
| HTML 생성 회귀 검사 | 개별 분석·비교·PR·평가, 중복 제거, 차단된 CRI, 검증 소스 링크, 시각 fallback 통과 |
| 텍스트 처리 | 설명·프로젝트 이름·숫자 필드에 HTML 모양의 문자열을 넣어도 활성 요소로 삽입되지 않음 |
| 오프라인 브라우저 | 5개 시나리오에서 외부 요청·스크립트·iframe·이미지 없이 열림 |
| 모바일·인쇄 | 390px 가로 넘침 없음, Chromium 인쇄에서 접힌 설명 포함 |
| 실제 UI 다운로드 | 개별 분석·범위 비교·PR·분석 중단 보고서 저장 후 오프라인 재열기 통과, 입력 토큰 미포함 |
| 실제 서버·공식 Petclinic ZIP | 실제 영향 분석과 3단계 비교를 HTML로 다운로드하고 오프라인에서 다시 열기 통과 |

실제 Petclinic 입력은 고정 버전 `500158f732419217507c7656904b8e6aa1bcc0d6`의 ZIP입니다.
실제 UI 검증은 API 응답을 가로채지 않았습니다. 별도의 결정적 UI 회귀 검사는 고정 API 응답을 사용합니다.
이번 변경은 frontend와 검증 도구이며 백엔드 알고리즘·API는 바꾸지 않았습니다. 백엔드 전체 테스트의 이전 통과 기록을 이번에 새로 실행한 검사로 세지 않습니다.

## 재현 및 산출물

frontend 의존성과 Chromium 설치 후 프로젝트 루트에서:

```powershell
node tools/report-unit.cjs
$env:BROWSER_CHANNEL='chromium'
node tools/report-browser-smoke.cjs
node tools/run-ui-smoke.cjs
```

실제 서버·브라우저 검증은 공개 ZIP 준비 후 backend 8080과 frontend 5173을 시작하고 실행합니다.

```powershell
node tools/report-live-smoke.cjs
```

`benchmark-output/live-impact-report.html`, `live-comparison-report.html`과 데스크톱·모바일 화면 캡처가 생성됩니다.
fixture 보고서와 UI 다운로드 산출물도 `benchmark-output/`에 남습니다. 해당 폴더는 Git에서 제외되어 있습니다.
CI에 HTML 생성·오프라인 브라우저 검사를 연결하고 HTML·화면 캡처도 artifact에 포함했습니다.
원격 Actions 실행, 배포, 설치본 재생성, 다른 브라우저의 인쇄 검증은 이번 실행에 포함하지 않았습니다.
