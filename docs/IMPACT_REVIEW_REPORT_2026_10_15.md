# 테스트를 통한 잘못된 영향 전파 수정 · 2026-10-15

공식 Spring 소스의 3가지 변경 가정을 검토해 포함·제외 대상 21개를 고정했습니다.
실행 결과, 테스트가 참조하는 다른 업무 코드로 영향이 전파되는 오탐 3개를 확인하고 수정했습니다.

## 확인한 문제

테스트가 둘 이상의 업무를 검증할 때, 테스트가 두 업무 사이의 운영 의존성처럼 취급됐습니다.

```text
JPA 쿼리 → 테스트 메소드 → Customer.getLastName()
수의사 저장소 → ClinicServiceTests → OwnerRepository
수의사 저장소 → ClinicServiceTests → Owner
```

JPA getter는 테스트의 검색 입력·assertion을 만들기 위한 호출입니다.
Petclinic 공유 테스트는 수의사와 보호자 기능을 별도로 검증합니다.
이 연결만으로 무관한 업무를 변경 영향으로 올리는 것은 LOCAL 검토에서 잘못된 확장입니다.

## 변경 동작

- 탐색 중 도달한 TEST 클래스는 검토 후보로 남기고 더 확장하지 않습니다.
- 테스트 클래스에 속한 메소드도 후보로 보존하며, 소속 테스트 클래스까지 연결합니다. 그 메소드의 다른 호출을 따라 업무 코드로 돌아가지 않습니다.
- 테스트를 거치지 않는 실제 업무 의존성 경로는 그대로 탐색합니다.
- 그래프 자체의 TESTS/CALLS 관계는 보존합니다. 영향 탐색 정책을 바꿨습니다.
- 변경 시작점 자체가 테스트일 때는 테스트 호출을 근거로 운영 코드 영향을 주장하지 않습니다.
- 결과 화면의 테스트 후보 안내에 이 경계를 표시했습니다.

이 정책은 LOCAL/FEATURE/SYSTEM 모두에 적용합니다. 소스 계약의 Owner 제외 기대는 LOCAL 범위에 한정합니다.
광역 범위에서는 실제 공통 기반 클래스 등 다른 정적 관계로 연결될 수 있습니다.
TEST 분류는 기존 테스트 어노테이션·명명 규칙을 사용하므로 런타임 커버리지 판정이 아닙니다.

## 수정 전후

| 고정 소스의 변경 가정 | 라벨 수 | 라벨 오탐 전 → 후 | 필수 후보 누락 전 → 후 | 테스트 후보 전 → 후 |
|---|---:|---|---|---|
| REST greeting 포맷 | 4 | 0 → 0 | 0 → 0 | 1 → 1 |
| JPA last-name 검색 | 7 | 1 → 0 | 0 → 0 | 1 → 1 |
| Petclinic vet 페이지 쿼리 | 10 | 2 → 0 | 0 → 0 | 6 → 6 |

케이스·소스 근거·동일 라벨의 수정 전후 결과는 [reviewed benchmark](../benchmarks/reviewed/README.md)에 저장했습니다.
provenance에는 공식 소스 커밋과 변경 전후 분석기·라벨 파일의 SHA-256이 있습니다.
수정 후 반환된 대표 경로는 실제 그래프의 인접 관계와 일치했습니다.
CI는 성공·실패와 관계없이 평가 TSV를 `analysis-evaluation-evidence` artifact에 보관하도록 연결했습니다. 이번에 원격 Actions를 실행한 것은 아닙니다.

## 실행한 검증

- 실제 Gradle 의존성 `test bootJar`: 39개 테스트, 실패·오류·skip 0.
- 새 회귀 검사 4개: 공유 테스트 경유 방지, 직접 테스트 호출자 보존, 별도 운영 경로 보존, 테스트만 변경한 경우의 경계. 세 분석 범위도 확인했습니다.
- 기존 핵심 검사 62개, 합성 30개, 공식 소스 구조 30개, 소스 계약 21개 통과.
- backend/frontend semantic 검사 및 실제 frontend 빌드 통과.
- 고정 Chromium의 UI 회귀 검사 통과.
- 실제 서버·브라우저에서 공식 소스 ZIP 3개, 영향·범위 비교·GitHub 커밋·소스 검증·모바일 흐름 통과.

이것은 전체 영향 범위의 정답 데이터셋이 아닙니다. 라벨 밖 후보는 평가에서 분리했습니다.
라벨은 소스를 검토한 에이전트가 실행 전에 작성했으며, 독립적인 사람의 검수는 아직 필요합니다.
CRI의 상대 순위 보정, 실제 테스트 실행, 원격 Actions, 설치본 재빌드·발표 PC 시연을 완료한 것으로 간주하지 않습니다.
